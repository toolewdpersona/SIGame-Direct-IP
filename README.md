# SIGame Direct IP

Неофициальный мод для **SIGame 8.14.1 / Windows x64**. Позволяет играть с друзьями через собственный хост, когда официальные игровые серверы недоступны. Участники могут подключаться из игры или браузера.

**[Скачать мод 1.0.8](https://github.com/toolewdpersona/SIGame-Direct-IP/releases/download/v1.0.8/SIGame-Direct-IP-v1.0.8.zip)** — готовый архив для установки. Отдельно устанавливать .NET и собирать проект не нужно.

## Установка

1. Закройте игру и откройте её папку через Steam → SIGame → Управление → Просмотреть локальные файлы.
2. Распакуйте архив мода в эту папку с заменой файлов. `SIGame.exe` и `DirectHost` должны лежать рядом.
3. Нажмите «Играть» в Steam. В главном меню **снизу справа** должна отображаться версия **Direct IP 1.0.8**.

**Если уже стоял старый мод:** удалите SIGame через Steam, затем удалите оставшуюся папку SIGame. Заново установите игру и распакуйте новый мод. Старые параметры запуска с `Play-DirectIP-….cmd` уберите, если добавляли их.

## Подключение

**Для игры через Интернет требуется эмулятор локальной сети либо белый (публичный) IPv4 и открытый порт у хоста.**

С эмулятором все участники подключаются к одной виртуальной сети и используют виртуальный IP хоста. Для прямого подключения по белому IP пробросьте **TCP-порт 51234** на роутере хоста и разрешите его в брандмауэре Windows.

- Хост: «Игра по IP» → «Создать хост» → выберите пакет и создайте комнату.
- Участник: «Игра по IP» → «Подключиться по IP». Порт по умолчанию — **51234/TCP**.
- Браузер: `http://АДРЕС_ХОСТА:51234/`; участнику не нужно устанавливать мод.
- `DirectIP-Tools/Allow-port-51234.cmd` при необходимости открывает порт в брандмауэре Windows, но не настраивает роутер.

Выход создателя удаляет комнату. Выход в главное меню выключает хост. Пинг и время нажатия переключаются в «Настройки → Общее → Игра по IP».

## Возможности

- Создание своего хоста и подключение друзей по IP:порту из игры или браузера.
- Прямая передача медиа вопросов с компьютера хоста.
- Аватарки PNG, JPEG, GIF, MP4 и WebM до 15 МиБ.
- Пинг и время нажатия внутри поля очков. «−» означает нажатие до разрешения отвечать, «+» — после; значения в миллисекундах.
- Дополнительные настройки: пинг и время нажатия можно включать и выключать независимо. Выбор сохраняется в «Настройки → Общее → Игра по IP».

Пинг, отклик (время нажатия) и аватарки размером до 15 МиБ доступны только в режиме «Игра по IP».

## Исходники и лицензии

В репозитории хранятся код мода и изменения к исходной игре:

- [`DirectHost/`](DirectHost/) — локальный сервер Direct IP.
- [`patches/`](patches/) — изменения клиента `SIOnline` и движка `SI`; [`upstream.json`](patches/upstream.json) закрепляет точные коммиты оригиналов и контрольные суммы патчей.
- [`README-BUILD.txt`](README-BUILD.txt) — требования и инструкция сборки; [`build-from-source.ps1`](build-from-source.ps1) — скрипт сборки для Windows.
- [`DirectIP-Docs/`](DirectIP-Docs/) — изменения, сведения о защите, лицензии и уведомления.

Скрипт сборки сам скачивает закреплённые версии оригиналов и применяет патчи. Полные папки `SI` и `SIOnline` в основной ветке не дублируются. Для обычной установки собирать мод не требуется.

В архиве `SIGame-Direct-IP-source-v1.0.8.zip` нужные исходники `SI`/`SIOnline` уже находятся с применёнными изменениями. Там также сохранены синтетические тестовые медиа, проверки и технические отчёты. Его собственный скрипт собирает вложенные исходники.

Оба способа сборки требуют Интернета для зависимостей npm, Cargo и NuGet. Кнопка Code → Download ZIP скачивает текущую ветку с патчами; файлы `Source code` в релизе — состояние репозитория на его теге.

Оригинальные проекты: [SI](https://github.com/VladimirKhil/SI) и [SIOnline](https://github.com/VladimirKhil/SIOnline), Vladimir Khil и участники проектов. Мод не является официальным обновлением и не заявляет одобрения авторов или Valve. Лицензии и авторство исходных проектов сохранены; сведения о сторонних компонентах и неуточнённых условиях приведены в [NOTICE.txt](DirectIP-Docs/NOTICE.txt).

Откат к оригинальной игре: закройте SIGame и проверьте целостность файлов в Steam. Ограничения защиты и сетевого режима описаны в `DirectIP-Docs/SECURITY.txt`.
