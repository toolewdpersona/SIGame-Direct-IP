SIGame Direct IP 1.0.8 — проверки и ограничения защиты

Повторная проверка опубликованного ZIP, 2026-11-16
- 414 клиентских тестов пройдены; 1 ранее отключённый тест пропущен.
- На сервере из релиза повторно пройдены проверки подключения и прав,
  PNG/GIF/MP4/WebM и границы 15MB, знака реакции и пинга, удаления комнат,
  30-секундного возврата владельца и четырёх автоматических вопросов без MOVE.
- В обычном HTTP-браузере проверены вход, статичное превью видеоаватарки,
  сохранение настроек показателей, вопрос и Space. Запросы игры идут к хосту.
- Повторены проверки Origin/Host, чужого управления, файлов/ZIP/XML,
  изоляции HTML, квот, параллельных загрузок и освобождения ресурсов.
- npm audit --omit=dev и проверка прямых/транзитивных NuGet-зависимостей
  не обнаружили известных уязвимостей. Это результат на дату проверки.
- Cargo audit сообщает об уязвимостях quick-xml и rkyv в общем lock-файле;
  эти пакеты не входят в дерево Windows x64 с steam_client. Предупреждения
  о неподдерживаемых библиотеках и отдельных unsound API остаются.
- Исполняемые файлы релиза не менялись. Сведения ниже включают проверки
  предыдущих сборок от 2026-11-15; это не гарантия отсутствия всех ошибок.

Что исправлено
- HTML-вопросы и SVG/HTML, открытые прямо по ссылке на медиа, получают CSP sandbox.
  Скрипты HTML-вопросов продолжают работать и отправлять события завершения, но
  не имеют доступа к родительской странице, localStorage и сетевому API хоста.
  В прямом режиме iframe также лишён allow-same-origin.
  Ограничение совместимости: HTML-паки, которым нужны fetch/WebSocket, формы,
  плагины или доступ к хранилищу сайта, в этом режиме не поддерживаются.
- Права локального управления требуют loopback-соединения И loopback Host.
  Подмена Host через DNS rebinding больше не раскрывает токен управления.
  Разрешены собственный origin и штатный origin Tauri; посторонние сайты,
  произвольные localhost-порты и opaque/null origins блокируются.
- У аватарок проверяются байты формата и реальный размер потока. Имя задаётся
  SHA-256, исходное имя пользователя не становится путём файла. EXE/HTML/SVG,
  переименованные в PNG, отвергаются. Файлы отдаются с точным MIME, nosniff,
  CSP sandbox; они не запускаются сервером как программы.
- Лимиты: 15MB на аватарку; 512MB и 128 уникальных файлов на сеанс хоста;
  повторная загрузка одинакового файла не расходует дополнительные слоты.
  До 4 одновременных загрузок, до 30 попыток за минуту с одного IP (при общем
  внешнем IP лимит общий). Превышение частоты возвращает HTTP 429.
- Пакеты: только локальное управление, один файл до 512MB, до 2048MB после
  распаковки, до 16 пакетов/4 ГиБ на сеанс. Проверяются пути, дубликаты,
  количество записей, размеры XML; DTD/внешние XML-сущности запрещены.
  Неудачная загрузка удаляет временные файлы. Имена медиа хеширует исходный
  распаковщик, выход за каталог не допускается.
- До 256 обычных соединений и 256 upgraded/WebSocket-соединений к серверу.
  Пароль комнаты, токен владельца и привязка отправителя к соединению сохранены.

Что проверено
- Подключение ведущего и игроков, неверный пароль, подмена имени/владельца,
  повторное подключение, передача PNG/GIF/MP4/WebM, byte ranges и граница 15MB.
- В браузере: скрипт вопроса выполняется и отправляет completed; чтение страницы
  игры, localStorage и fetch к API блокируются. Проверено и открытие HTML напрямую.
- Подмена Host без Origin, посторонние/null origins, запрос остановки без токена,
  подмена MIME/имени файла, traversal, DTD, большой XML и повреждённые ZIP.
- Квоты аватарок по числу и суммарному размеру, дедупликация и очистка сеанса.
- Четыре медленные загрузки занимают доступные слоты; отмена освобождает слоты.
- Нормальная игра в браузере, Space, общие показатели; автоматическое прохождение
  четырёх вопросов с текстом/видео/изображением/ответами без команд MOVE.

Зависимости
- npm audit --omit=dev: 0 известных уязвимостей после обновления grpc-js.
- NuGet: известных уязвимых прямых/транзитивных пакетов не обнаружено.
- Rust: обновлены совместимые версии h2, webpki, корневых сертификатов, anyhow,
  rand и других затронутых зависимостей; выполнена полная пересборка EXE.
  Полный Cargo.lock всё ещё содержит предупреждения quick-xml и rkyv для
  неактивных платформ/функций: этих библиотек нет в дереве Windows-сборки
  x86_64-pc-windows-msvc с steam_client. Есть уведомления о неподдерживаемых
  библиотеках и специальных случаях unsound API (включая Unix AsyncFd Tokio).
  Поэтому результат не обозначается как «весь Cargo.lock полностью чист».

Размер и пинг
Сохранены целиком небольшие игровые сборки и модели, используемые через
reflection/JSON/SignalR. Удаляются неиспользуемые части .NET. Предупреждения
IL2026 о reflection сохранены в журнале; соответствующие модели защищены
TrimmerRootAssembly и проверены на опубликованной сборке, не только Debug.
Ответы на ping больше не вызывают отдельную рассылку всей комнаты. Общий
снимок отправляется раз в 2 секунды; реакции/смена попытки/вход/выход — сразу.
Проверка: 2 снимка за 5,1 секунды, доставка реакции около 110 мс локально.
Это измерение теста, а не обещание задержки через Интернет.

Оставшиеся риски
Это проверка кода, зависимостей и выбранных сценариев, а не гарантия отсутствия
всех уязвимостей и не антивирусная сертификация. Сигнатура формата не доказывает,
что произвольный медиафайл безопасен для любого декодера. Держите браузер,
WebView2 и Windows обновлёнными; неизвестная ошибка декодера остаётся возможной.
Даже небольшой по размеру GIF/видеофайл может сильно нагружать декодер клиента;
ограничение размера файла само по себе не ограничивает нагрузку на CPU/GPU.
HTML-пак не получает доступ к странице игры, но может содержать нежелательный
текст/изображения или пытаться обращаться к внешним ресурсам через медиа-теги.
Обычный HTTP не шифрует трафик, пароль комнаты и медиа. Подключение по IP
не является защищённым туннелем. Лимиты сдерживают расход ресурсов, но не
защищают от распределённого DDoS и перегрузки интернет-канала. Не запускайте
игру с правами администратора; открытый порт предназначен для доверенной группы.

возвращают в главное меню и останавливают хост без подтверждений. Выход

Сборки dev, Steam,
web и .NET выполнены. В изменённых файлах и новом тесте ошибок ESLint нет;
общий lint проекта остаётся с прежними ошибками, включая конфигурацию тестов.

Проверка библиотек 1.0.6
- Каталоги и импорт доступны только через loopback с loopback Host.
  Запросы гостя, постороннего Origin и подменённого Host получают 403.
- Клиент передаёт идентификатор каталога и пакета, не произвольный URL.
  Разрешены два заданных API, HTTPS-пакеты SIStorage, документы VK и CDN userapi.
  Каждое перенаправление проверяется; сокет привязывается к публичному IPv4,
  исключая loopback, LAN и link-local даже при смене DNS. Прокси ОС не используется.
- Ответ каталога до 8MB, файл до 512MB по фактическому потоку, максимум
  две загрузки одновременно, 5 перенаправлений, 5 минут на импорт.
  Временный архив удаляется после импорта или ошибки. Далее действуют
  прежние проверки SIQ/ZIP/XML и квоты. При недоступном файле показана ошибка.
- Проверены реальные загрузки из обеих библиотек и случайные темы на trimmed
  сервере, создание комнат, выбор в EXE, мастерская и локальный пакет.
  412 клиентских тестов пройдены, 1 ранее отключённый пропущен.
  Автопереходы: 4 вопроса без MOVE; браузер: вход, медиа и Space/реакция.
  Старые ответы каталога больше не подменяют список после смены библиотеки.
  Новые и затронутые исходники/тесты ESLint: 0 ошибок.
