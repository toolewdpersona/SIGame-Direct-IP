SIGame Direct IP 1.0.8 — Windows x64, неофициальный мод

Установка
1. Закройте игру. В Steam: SIGame → Управление → Просмотреть локальные файлы.
2. Распакуйте архив в папку игры с заменой файлов.
   SIGame.exe и DirectHost должны лежать рядом.
3. Нажмите «Играть» в Steam. В главном меню снизу справа — Direct IP 1.0.8.

Если уже стояла старая версия
1. Полностью закройте игру. Удалите SIGame через Steam,
   затем удалите оставшуюся папку SIGame целиком.
2. Заново скачайте и установите SIGame через Steam.
3. Распакуйте новый мод в папку игры с заменой файлов и нажмите «Играть».
Старые параметры запуска с Play-DirectIP-….cmd уберите, если добавляли их.

Как играть
Хост: «Игра по IP» → «Создать хост» → выбрать пакет и создать комнату.
Друг с модом: «Игра по IP» → «Подключиться по IP». Порт: 51234/TCP.
Друг в браузере: http://АДРЕС_ХОСТА:51234/ — мод устанавливать не нужно.
Для игры через Интернет у хоста нужен белый (публичный) IPv4-адрес.
На роутере хоста пробросьте TCP-порт 51234 на локальный IP его компьютера;
друзья подключаются по белому IP хоста.
Другой вариант — программа для создания виртуальной локальной сети:
все участники подключаются к одной сети и используют виртуальный IP хоста,
в том числе при игре в браузере. Белый IP и проброс игрового порта тогда не нужны.
При необходимости запустите DirectIP-Tools/Allow-port-51234.cmd:
он открывает порт в брандмауэре Windows, но не настраивает роутер.
Выход создателя удаляет его комнату. Выход в главное меню выключает хост.
Пинг, отклик (время нажатия) и аватарки размером до 15 МиБ
доступны только в режиме «Игра по IP».
Пинг и время нажатия: Настройки → Общее → Игра по IP.

Откат: закройте игру и проверьте целостность файлов SIGame в Steam.
Подробности, ограничения и лицензии — в DirectIP-Docs.
